# ore-decision (issue #2836)

Chosen: the hybrid of idea A and idea B. A: an Assets item-menu entry "What to do with this ore" opening a three-way comparison dialog (sell raw, refine then sell, use in a Build Plan). B: on a Build Plan, a per-mineral line "Your ore could cover ..." plus an Ore toggle that counts ore into Have, tracked as its own source. Idea C (a new Mining > Ore tab) is not built.

First draft mockup; sample data. The ticket text wins over the picture where they differ. `today-*` boards show the current screens.
