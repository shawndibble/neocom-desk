The Overview, built by the pilot: final free grid design

This is option A, refined after a hostile review from a first-time user. The Overview is a grid of widgets the pilot adds, sizes, renames and removes, each shown as a number, a chart or a list. The alerts bell is in the header of every page. Use Customize, the ⋯ menu on any widget, and the bell. Both frames share one layout. Figures are invented, and the numbers do not change when you switch character.

Review controls Widget states

What the hostile review changed

  • First run asks what you do. Pick roles and the grid is built from them. Customize has Start from a role, so it is always reachable.
  • The headline number is never hidden. A Small chart still shows its value. Wallet defaults to a number with a trend line.
  • Danger is on the page. A banner under the header names the active danger alert and needs Acknowledge. The badge is red only for danger and blue otherwise. Mark all read leaves danger alone.
  • Every widget has real states: loading, needs permission with Grant access, failed with Retry and the last good value, and empty with Remove.
  • One deadline. The header chip is the only Next deadline. It turns amber under 3 hours and red under 30 minutes.
  • Customizing is safe. Undo on remove, add, reset and size. Reset asks first. Cancel sits beside Done. View switching moved into the ⋯ menu, so a stray click changes nothing.
  • Reading order is screen order. Rows are packed without holes, so ↑ and ↓ do what they say. Move to top and bottom are in the menu.

And

  • Per-widget settings in ⋯: view, character, date range, rename, duplicate, hide on phone. You can add the same widget twice.
  • Character scope is per widget (Header character or All characters in its ⋯ menu); the header has no switcher.
  • Honest charts. Orders no longer treats Expiring as exclusive. Wallet flow splits income and spending. Net worth has no red. Bars carry a max and a time range. Every chart has a text equivalent in its List view and a hidden summary.
  • Gallery previews are readable. Each is a real Medium widget, and "New" only shows for returning pilots.
  • Phone customization is reorder, remove and add. Sizes and views are set on desktop. Rows are 44px. The earlier phone bug is fixed.
  • Alerts: working type filters, an empty state, Esc and outside click close the panel, phone rows have View, Snooze and Dismiss.
  • Widgets the pilot never added never fetch, and a soft limit of 30 widgets keeps the page bounded.

Still open

  • Does the layout sync per account or per device? The hidden cards setting syncs today, so I'd sync this too.
  • Phone and desktop order. One list now, with Hide on phone per widget. A separate phone layout is the alternative.
  • Widget data for All characters. Which widgets can sum across characters, and which only list them.
  • Which alert types raise the banner. Today only danger does.
  • Missing scopes. The Grant access action should reuse the app's existing Grant note.
