## Calculations worth borrowing

- Lawless = insurgency `corruptionState` max (5). Public, unauthenticated; CORS unknown (check; else needs proxy).
- Profit with Accounting skill (sales tax = 8% x (1 - 0.11 x level), broker by skills/standings): we already compute (standings via contacts.md).
- Rating = reward / base rate by jumps (Haulers Channel). We have going-rate corpus.
- Route graph from SDE, not ESI `/route/`: ESI lagged new gates by months.

## Candidate gaps

1. Lawless/insurgency marker on Route Safety rows (and contract route exposure). Confirmed in thread (posts 12-16). Small. Risk: unofficial endpoint, no guarantee.
2. Verify SDE stargate graph has Cradle of War connections; add a test pinning Jita-Amarr jump count. Cheap.
3. Hauling scan: widen from hub-to-hub to "stations within N jumps of hub" (Courier does 10). Single tool; moderate.
4. Gatecamp verdict derived from kills + pod kills + zKill in last hour (we show raw numbers; maybe fine per "numbers not verdicts" decision in pilot-lookup.md).
