## What the dogma engine is trusted for (ADR 0016)

`docs/adr/0016-*.md`: stats come from `@eveshipfit/dogma-engine` (WASM) + `@eveshipfit/sde` `sde.dat`, pinned together. Via the seam `src/features/fittings/dogmaFittingEngine.ts`; `src/engine/fittings/stats.ts` only reads attributes. So these are NOT our code and have no formula in the repo: stacking penalty and order, skill/ship/implant/booster bonuses, CPU/PG/calibration totals, capacitor capacity/recharge/peak load, resists and EHP, speed/agility/align time, drone bandwidth totals and max active drones, overload bonus, mining amount/crit/waste base values, abyssal weather beacons' effects. ADR: no heat damage or burnout model, only overload bonus.

Own tests assert only plumbing (`stats.test.ts:46-56` reads `cpuOutput-cpuFree`, EHP 24187.5 is a fixture value, not an independent derivation). `node_modules/@eveshipfit` is not installed in the worktree, so the engine itself could not be run here.

How to prove the engine (proposal, no code written):

1. Golden-vector test per attribute class: load a fit with all-V skills, compare engine output to a published independent source: Pyfa/EVE Workbench export of the same EFT, or in-game client numbers via the ESI `/dogma/` + SDE `typeDogma` hand-calc. Each vector below gives hand arithmetic.
2. Vectors that need no engine data, only the SDE attribute values: stacking (below), EHP, align time, capacitor.
3. Pin-bump gate: when `@eveshipfit/sde` is bumped, rerun the golden vectors; failing vector = block bump.

Hand-calculated vectors (independent of engine):

- **Stacking** S(n)=e^-((n)/2.67)^2, n=0.. : 1, 0.86911, 0.57058, 0.28296, 0.10599, 0.03000. Check: n=1: (1/2.67)^2=0.14025, e^-0.14025=0.8691; n=2: 0.56099 -> 0.5706; n=3: 1.2622 -> 0.2830; n=4: 2.2440 -> 0.1060; n=5: 3.5062 -> 0.0300. All six wiki multipliers (100/86.9/57.1/28.3/10.6/3.0 %) reproduced.
  - Three +20% damage mods (multiplicative, penalised): 1.2 x (1+0.2x0.8691) x (1+0.2x0.5706) = 1.2 x 1.17382 x 1.11412 = 1.56934.
  - Three 30% armor resist mods on 0% base (damage-taken factor): 0.7 x (1-0.3x0.8691) x (1-0.3x0.5706) = 0.7 x 0.73927 x 0.82882 = 0.42890 -> 57.11% resist.
  - Order: strongest first, positive and negative groups separately (wiki). Engine-trusted.
- **EHP** layer = HP / sum(w_i x (1-r_i)). HP 1000, resists EM 0, Th 0.5, Ki 0.5, Ex 0.75, uniform profile 0.25: 0.25x(1+0.5+0.5+0.25)=0.5625 -> 1777.78.
- **Align time** = -ln(0.25) x inertiaMod x mass / 1e6 s (CCP formula, wiki page 404 so unverified on wiki). Frigate mass 1.2e6 kg, inertia 3.2: 1.38629 x 3.2 x 1.2 = 5.323 s.
- **Capacitor** (ours, `tank.ts:176-197`): C=1000 GJ, tau=200 s, drain 10 GJ/s. L = drain x tau/(10C) = 0.2; sqrt(s)=(1+sqrt(1-0.8))/2=0.72361; stable at s=0.52361 -> 52.36%. Drain 20: L=0.4, a^2=0.15, a=0.38730; atan(1/(2a))=atan(1.29099)=0.91174; t=(200/10)x(2/0.38730)x0.91174=94.16 s. Peak recharge 2.5xC/tau=12.5 GJ/s at 25% (wiki: peak 25%, 2.5x average).
