  `20261002-165816-shortcuts-move-to-help-always-on-and-lose`. A new pilot,

  app.** Five questions (EVE words, making ISK, first ship and training,
  security bands, where to learn more), each pointing to the app page that
  helps and out to EVE University and CCP for the rest. It is FAQ content, not
  a tour or a first-run panel, so declined decision C80 stays declined. Term
  tooltips and a separate glossary page are not part of it.
