# Scope decisions — Net worth estimates days with no snapshot

_Recorded 2026-11-09._

- **The net worth chart estimates days with no snapshot.** A missed day dipped to the wallet alone and read as a collapse. Non-wallet layers are interpolated between neighbouring snapshots, repeated from the first before it (new users) and from the last after it; the wallet stays the real journal balance. Estimated days are hatched with a dashed outline. This reverses the earlier "nothing is interpolated" rule.
