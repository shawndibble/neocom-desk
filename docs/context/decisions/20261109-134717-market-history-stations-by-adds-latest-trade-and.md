# Scope decisions — Market History Stations by adds Latest trade and defaults to it

_Recorded 2026-11-09._

- **The "Stations by" picker gains Latest trade (station with the newest fill first) and it is the default.** Net ranked a station by ISK, which says little about where you traded; newest-first matches the row order inside each group. Supersedes the Net, Name, Trades list and Net default in `20261030-180611-market-history-by-station-view-and-station-filter.md`. A URL that sets `txn.stationsBy` explicitly is unchanged.
