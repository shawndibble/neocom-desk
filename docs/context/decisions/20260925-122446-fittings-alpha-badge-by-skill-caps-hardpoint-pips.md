# Scope decisions — Fittings: Alpha badge by skill caps, hardpoint pips, Ring right-click menu

_Recorded 2026-09-25._

- **The Fitting header says "Alpha OK" or "Omega only", by skill caps alone.** Every skill the hull, modules, charges and drones need — with the prerequisites beneath them — is checked against the SDE's Alpha clone caps (`alphaMaxLevel`; none means Alphas can't train it). It is a property of the fit, so it shows with no Character, and the tooltip names each skill level that keeps an Alpha out. It is the same test EVE Workbench's "Alpha Suitable" makes and agreed with it on the fit compared; it knows nothing of the few Alpha limits that aren't skills. A type ESI can't supply counts as needing nothing rather than blocking the badge, as the skill gaps already do.
- **The Ring marks the hull's hardpoints as pips on the rim's top gap** — turrets out left from 12 o'clock, launchers out right, between the calibration and bandwidth bands — filled where the high slots take one, red past what the hull has, each kind's numbers on hover. Totals are the ship's attributes (102, 101); what is taken comes from each fitted type's `turretFitted` / `launcherFitted` effect on ESI, read through the same cached type lookup as the skill requirements. Until every high-slot type is known, no pip shows as taken.
- **A fitted Ring tile has a right-click menu on a mouse or trackpad**: the states the module can reach (the one it's in ticked), unload its charge, show info, swap for a variation (the module dialog, variations open) and remove. Not on touch — Radix opens a context menu on long-press, which is the tile tooltip's gesture there — and not on the phone overview; the module dialog stays the keyboard and touch way to all of it.
