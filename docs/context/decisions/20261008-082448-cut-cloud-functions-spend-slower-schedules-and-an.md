# Scope decisions — Cut Cloud Functions spend: slower schedules and an archive-unchanged skip

_Recorded 2026-10-08._

- **Cloud Functions was the largest line on the bill (about $1.65 of $2.06 in the first 8 days of October 2026), so the two 9-minute jobs and the 5-minute dispatcher were slowed or made skippable.** `syncPublicContractOffers` keeps its 30-minute tick but a HEAD request first compares EVE Ref's ETag (or Last-Modified) with the one stored in `systemConditions/publicContractsArchiveFingerprint` after the last publish, and returns without downloading when it is unchanged; an unreadable fingerprint always syncs, and it is stored only after the write so a mid-run refresh is caught next time. `syncWorkbenchFits` runs every 12 hours, so its first pass over about 38k fits takes about 20 days instead of one. `dispatchProjections` runs every 15 minutes, so a Scheduled Push can arrive up to 15 minutes after its `fireAt`.
- **Skipping unchanged chunks of the contract snapshot was considered and not done.** Rows are sorted by type id, so one added or removed contract shifts every later 3,000-row chunk boundary and almost no chunk is byte-identical between runs. It would also break the `publishedAt` stamp readers use to detect a torn read (`chunkedSnapshot.ts`, `publicContractOfferIndex.ts`), which requires every chunk to carry the meta doc's `lastSyncedAt`.
