# Scope decisions — Skill Plan header: no Next step chip; Booster rows have no on/off box (issue #1409)

_Recorded 2026-09-26 · issue #1409._

- **No Next step chip in the Skill Plan header.** Added by #1409, removed: it
  only restated the first unfinished row of Your entries, one glance below.
  Don't re-add a header chip that names a single entry.
- **The what-if chip sits in the header's stat strip.** A What-If Implants lens
  re-costs every headline number, so its gain or loss is one of those chips,
  not a loose pill under the panel.
- **A Booster row has no on/off box.** A listed row is live; the X removes it
  and "Add accelerator" makes one. Rows an older build saved unticked are
  dropped on read, since nothing could turn them back on. Still an answer:
  a plan whose rows are all gone does not re-prefill a detected accelerator.
- **The booster market link opens Cerebral Accelerators (market group 2487),**
  not the Booster group (977), whose slots hold combat boosters.
