# Scope decisions — Wallet range is one page setting in the header

_Recorded 2026-11-09._

- **The Wallet's 7 / 30 / 90 day range is one page setting, in the page header beside Refresh, and drives both the Worth chart and ISK flow.** The two charts showed the same stretch of time but only ISK flow had a picker. The control sits level with the header icons (segmented buttons from `md`, a select below it so a phone header keeps its title and Character picker) and only on the Balance tab. ISK flow lost its own picker. Estimates are drawn from the whole series before the range slices it, so a range edge never changes them.
