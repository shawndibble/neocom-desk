# Scope decisions — Appraisal refine breakdown modal and share link carry the refine setup

_Recorded 2026-11-01._

- **One breakdown modal, two scopes.** The Refine chip's ⓘ opens it for the whole pile; a row's Refine figure opens it for that item at the pasted quantity. Inside, an "All items" action and the by-item table move between the two. It shows the verdict (sell as is into buy orders against refine then sell the minerals), the break-even total efficiency, the minerals with quantity, price and value, the tax and leftover lines, and for one item the batch arithmetic. The point is that every figure can be checked against another tool.
- **Sell-order listing is not part of the verdict.** A list price is unreliable on thin books (one uncompressed ore sat at 46× its compressed price), so the comparison is as-is into buy orders against refine only, both at the hub's best buy price. The breakdown says that a very large pile sells for less.
- **The Facility yield and Reprocessing tax chips do not return to the result header.** They were moved into the page settings modal on purpose (#5531). The breakdown modal carries the same fields for editing in place, and the Refine chip shows the total efficiency beside its figure (`@ 68.3%`) so the 50% NPC-station default is never silent.
- **A share link carries the sharer's resolved numbers, not their skills.** Each refinable item stores its recipe and the efficiency applied to it (facility yield × skills × implant), and the link stores the facility yield, tax and the minerals' names and prices as quoted. A signed-out visitor sees exactly the sharer's figures. Additive fields on snapshot version 1; an older link has none and shows no Refine, and an older build opening a newer link ignores them.
- **A shared link opens on the sharer's numbers.** "Use my numbers" swaps in the visitor's own Refining Setup and skills at the same shared mineral prices, so only the numbers that are theirs move, and "Back to shared numbers" returns. It needs an active Character; signed out, it says why. The reprocessing data is read only once the breakdown is opened.
