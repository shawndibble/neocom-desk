# Scope decisions — Due soon and Structures read every corporation by default when there are two (issue #6088)

_Recorded 2026-11-11 · issue #6088._

- **Due soon joins Structures and Moon extractions in reading every corporation.** One player kept one structure in each of 13 corporations and switched Character 13 times to see fuel and timers. All reads each Due soon source (fuel, timers, extractions, jobs, starbases, sovereignty) per corporation, only where some Character's roles and grant open that source there; a corporation that cannot be read for a source is left out of it, never an error. Rows from every corporation rank as one list.
- **The corp widgets' All choice is offered only when two or more corporations are readable for the kind.** With one, All would draw the same rows, so the menu offers nothing and a widget saved on All reads the header Character's corporation, keeping the saved choice for when a second corporation appears. Until the count is known the header scope is read, so a one-corporation pilot never fans out. The menu reads **This corporation / All my corporations**. Moon extractions follows the same rule, so no corp widget offers a choice that changes nothing.
- **On the Corp Board, Due soon and Structures open on All**, in the default layout and when added from the Gallery. Moon extractions and the Overview's widgets still open on the header Character. A layout saved before this keeps what it saved.
- **A Corporation column (ticker, full name in the tooltip) appears when the rows come from two or more corporations**, superseding "no Corporation column yet" in `20261111-221423-structures-and-moon-extractions-widgets-can-read-every.md`. A corporation whose read failed leaves the rest drawn and the widget flagged as partly failed.
- **One helper picks the reader**: `corpReadersFor` / `accountCorpReaders` (`features/corp/corpReadAccess.ts`), one Character per corporation, the active one preferred, account order. Industry's corp jobs moved onto it; its candidate check now also requires the roles scope, without which the roles read could only 403.
