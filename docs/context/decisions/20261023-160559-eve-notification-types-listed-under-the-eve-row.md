# Scope decisions — EVE notification types listed under the EVE row

_Recorded 2026-10-23. Amends the EVE notifications bullets of `20261014-173602`._

Reaching an EVE notification type took two openings: the EVE notifications row, then the type row for its Characters.

- **The families and their type rows are listed directly under the EVE notifications row, never behind it.** The row still opens, to its own per-Character chips, so the master switch keeps its exceptions. Each type row still opens to its Characters.
- **On a phone the types sit on the EVE Topic page.** No sheet opens first; a type row's Characters open inline, as before, so Back keeps returning to the Topic list.
- **A search shows only the single EVE notifications row.** The type list is the longest on the page and would bury every other match. This replaces "never the EVE notifications row" as the rule only for the type list; the row itself is still never opened by a search.
