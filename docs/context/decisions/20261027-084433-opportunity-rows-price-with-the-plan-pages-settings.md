# Scope decisions — Opportunity rows price with the plan page's settings

_Recorded 2026-10-27._

- **Market-Wide, Ranked builds and All owned price every row with the settings the plan page starts a plan with**: the Character's latest plan (its Trade Hub, its material price basis, and its build location when none is remembered) plus the remembered build location, assumed ME/TE, standings, skills and LP Value. A row used to price at a fixed Jita (Market-Wide), at sell orders always, and without the latest-plan location fallback, so a pilot who buys on buy orders or last built at Amarr saw a row and a plan that could not agree. The plan opened from a row starts from the same latest plan (`defaultsFrom`), so the figures agree by construction.
- **Market-Wide's hub is the latest plan's hub, not a fixed Jita.** Supersedes "Hub fixed `DEFAULT_TRADE_HUB`, no picker" in `docs/features/industry-records-sourcing.md`. The sales-volume region follows it (`20261027-070014-*`). A pilot with no plan keeps Jita.
- **Ranked builds and All owned buy materials at the plan's price basis** (`materialPricesFor`), the same side of the book the plan page and its make-or-buy verdicts read.
- **What still differs from the plan page, by design:** Depth Prices (an order-book walk per large material need, one request per material, for the one plan the page shows), Community Offers (read by a page hook), a plan's own overrides (cost index override, Include Reactions, hand-set material prices) and its Owned materials scope. Rows are computed for hundreds of blueprints at once; these are per-plan choices a row has no plan to read.
- **Ranked builds and All owned count the stock a row uses at what it would sell for, as the plan's hero does by default.** The plan page's headline (`profitOnBasis('sellValue')` over an instant sale of the owned stock, `planOwnedStockSale`) charges the materials the pilot already holds at their sell value, so profit reads as what building earns over selling them. Rows counted them as free, which put an Infiltrator I at 144.5K ISK/hour on the row and 8K on its plan. Rows now take the same two functions (`onPlanHeroBasis` in `opportunities.ts`): profit, margin, ISK/hour and break-even move; cost columns keep the plan's own total cost, and a row with no stock, or stock with no buy-side price, keeps the plan's own figure, as the page does. Supersedes the last two bullets of `20261027-074537-*` ("Not changed: owned stock counts as free" and the price-basis note): the seeded plan now starts from the latest plan's basis, and the row's figure agrees with the plan's default hero.
- **Snapshots are per hub and build system.** A snapshot carries one system's cost index, so two Characters at one hub who build in different systems are priced from separate requests (`groupCandidatesByHub`).
- **A rebuilt latest-plan lookup does not reprice.** Rows reprice when what they read off the plan changes (`planSettings`: hub, basis, facility, rigs, tax, security, build system), not on every plan write; the Market-Wide scan key carries the same projection.
- **A plan opened from a row belongs to the active Character** but starts from the row owner's latest plan, as the row was priced.
- **A loss row names the stock it charged.** The row carries `forgoneSale`; its loss tooltip reads "Build cost X, plus Y for your own materials counted at what they would sell for, vs. sell price Z" when Y is charged, so the three figures add up to the profit shown.
- **Market-Wide rows stay stock-agnostic**: they claim no owned materials, and the plan a Market-Wide click opens starts unclaimed, so the two agree; the sell-value basis applies where a row uses held stock (Ranked builds, All owned).
- **Known gap: Compare.** Build Plan Compare reads each plan's own profit (the free basis) and has no sale of owned stock to net off, so a plan added from a row can read higher there than the row. Left as is.
