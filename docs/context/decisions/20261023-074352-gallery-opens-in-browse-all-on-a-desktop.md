# Scope decisions — Gallery opens in Browse all on a desktop

_Recorded 2026-10-23._

- **A desktop opens the Gallery in Browse all; Quick add is one press away.** With 30+ kinds the
  wide view is the better first look, and the drawer stays for a quick add. A phone is
  unchanged. This supersedes "keep the 460px drawer as the default" in
  `20261023-064612-gallery-browse-all-widens-the-one-drawer.md`.
- **Browse all is 80% of the page** (capped at 88rem), up from 70%. The category rail is 15rem
  from the `lg` breakpoint up, with a 2rem gap to the cards; below it the categories are one
  scrolling row above the list.
