# Scope decisions — One page per refinery, refinery name first (Refineries tab) (issue #6348)

_Recorded 2026-11-17 · issue #6348. Supersedes 20261116-233358 (a moon name links to its moon page)._

- **A refinery is the page's key, not a moon.** The Moons tab is **Refineries**, and `/corp/moons/refineries/:structureId` is one page for the book's own refineries and moon owners' alike. Archive is stored per refinery, and one moon can have several refineries over time, so a moon-keyed page would hide that. The refinery name leads everywhere (list row, header, links); the moon is dim text, "Moon not known yet" until an Extraction names it (decision 20261115-173527).
- **The moon page and the moon owner's refinery page are folded in.** The old `/corp/moons/moons/:moonId` redirects to the refinery of the moon's newest Extraction; `/corp/moons/moon-owners/:owner/refineries/:id` redirects to `/corp/moons/refineries/:id`. A moon with no Extraction has nowhere to go and says so. Archive / Restore, the offer hint (R3, 20261117-091850) and the label pencil carry over unchanged, for a moon owner's refinery only.
- **The page reads moon docs, never the full ledger.** One read of the refinery's `moonDocs` (`where structureId ==`) plus the book's core records. **Mined** is the ore mined inside each Extraction's window (fracture to field end), valued at today's hub prices and labelled estimated; mining outside a window is not counted. The monthly mining table is dropped: the Extractions table's Mined and Miners columns are the history, one row per pull.
- **Tax on the page is the tax Late notices already billed** (`frozenTax` in the doc), labelled **Tax billed**. Unbilled days need ledger rows, which the page does not load; the Extraction's own page still shows them.
- **Archive state on the page comes from the docs.** "Mining reappearing" for an archived refinery, and the idle offer, read the docs' windows (a doc's mining is dated its window's last day, never after today). The Moon owner page keeps reading ledger rows, so the two can differ by a mining day outside any window.
- **Miners: all of them, biggest mined value first, never capped or paged.** No per-Miner tax (a doc holds tax per Extraction only). On a phone the Miners table is a compact three-column table (Miner, Share, Mined).
- **Archived refineries leave the Refineries list** for a folded "Archived (N)" section under it, with Restore.
- **Not built:** Link a Survey on Ore unknown (its dialog is the Extraction page's and does not drop in unchanged); the Owner filter chips; an origin crumb from the Moon owner page. The crumb always reads "Refineries".
