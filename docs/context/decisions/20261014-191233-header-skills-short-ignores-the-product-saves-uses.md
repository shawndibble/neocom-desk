# Scope decisions — Header skills short ignores the product; saves uses compact ISK

_Recorded 2026-10-14._

- **The plan header's "skills short" counts only materials set to build.** The product's own blueprint is no longer counted, so a plan that buys every material shows no marker. This amends `20261014-183818-skill-gate-marker-follows-the-build-not-the.md`, which counted the product too.
- **Green "saves" figures on the Materials table use compact ISK** (`formatIskCompact`, "3.3M") rather than the full amount, so the figure fits beside Build instead on a narrow column.
