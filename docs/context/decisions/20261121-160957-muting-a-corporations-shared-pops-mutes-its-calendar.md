# Scope decisions — Muting a corporation's shared pops mutes its calendar events too

_Recorded 2026-11-21. Supersedes the "sharing corporation is muted" exception in `20261121-100024-shared-moon-pop-alert-body-names-the-refinery`._

- **A muted sharing corporation's pops still stand in for their in-game calendar events in the alerts.** Muting is dismissing that fleet; letting the corp's calendar event alert in its place was the same duplicate by another door. The calendar poll drops an event that matches a pop of a muted corporation, so a mute silences both.
- **The two exceptions stay.** Shared moon pop alerts off for the Character, or the Character outside the pop's audience: the event is then the only alert there is.
