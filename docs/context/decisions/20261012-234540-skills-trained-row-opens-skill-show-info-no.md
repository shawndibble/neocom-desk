# Scope decisions — Skills Trained: row opens skill Show info; no inspector, no implant list

_Recorded 2026-10-12. Supersedes the Trained-row bullet of
`20261012-154348-skills-trained-is-a-group-board.md` (name links to the info
modal, the rest of the row opens the inspector)._

- **The whole Trained row opens the skill Show info, the same as its name.**
  The inspector card above the list is gone: it duplicated the Show info
  (description, prerequisites, unlocks) minus the price, and opened at the top
  of the page, away from the row. The §6c Override for Skills › Trained is
  removed; the page now follows the default.
- **Add to Skill Plan lives in the skill Show info.** It adds the first level
  neither trained nor already in the target plan, counting levels the plan
  trains as prerequisites of other entries, so a plan already at III offers
  IV, not "Planned". Every surface that opens a skill's Show info gets it.
- **The Trained page no longer lists fitted implants.** Their attribute bonus
  still shows in the Attributes chips. The implant list and the "N of 5 slots
  empty" note are dropped; Clones is where fitted implants are read.
