# Scope decisions — Plan rows have no Move up/down control

_Recorded 2026-09-25._

- **A Skill Plan's entry and Remap Marker rows carry no Move up / Move down button or menu.** Reordering is drag (or the drag handle's Space + arrow keys) only. The row is already crowded on a phone — drag handle, name, milestone menu and remove button share one line — and every extra icon slot squeezes the name column. This removes the "Move" menu #1493 added (WCAG 2.5.7 alternative) and rules out re-adding standalone Up/Down buttons (#223, reverted earlier for the same reason) or any other per-row reorder control.
