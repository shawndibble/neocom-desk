# Scope decisions — Abyssal Item Detail

_Recorded 2026-10-16._

- **Item Detail states an abyssal type from its base modules and mutaplasmids, not its own shard.** The abyssal type's typeInfo shard carries almost none of the attributes a pilot opens it for (CPU, range, activation cost come from the base and the roll), so Item Detail adds a section built from `mutaplasmids.json` and the base module's shard: which bases and mutaplasmids make it, and what each mutaplasmid can roll on a chosen base, in absolute values. One abyssal type is made from up to 44 bases, each with its own values, so the table needs a base picker; a single "typical" table would state numbers for a module the pilot may not have.
- **The table starts on the Tech II base, else the first base by name.** The Tech II module is the base most pilots roll. Rejected: the lowest type id (often an obscure meta module) and showing every base at once (44 tables).
- **Values are shown in the game's units, and the "better" direction is in words.** Durations show in seconds and resonances as resistances (`engine/fittings/attributeUnits.ts`), which re-orders a range and flips its direction; each attribute says "Higher is better" or "Lower is better" rather than leaning on colour. A mutaplasmid's own page shows its rolls as ±% of the base value, with the direction of the multiplier.
- **One owned module rides in the info URL as `?info=type-<typeId>-<itemId>`.** The item id is what ESI's dynamic item and MutaMarket key on, and a URL keeps Back, new-tab and copy-link working as for any Show info. Assets adds it only to abyssal stacks, so every other item's link is unchanged; `ItemInfoLink`, `showInfo` and the item menu take it as an optional extra. Opened on an owned module, Item Detail shows its rolls against its base with roll quality, and its attribute list is the module's own (ESI's dynamic item carries the full set) instead of the type's sparse shard.
- **An abyssal type shows no best sell or best buy.** No market order exists for a mutated item, and the base module's price is not its price (`*-mutamarket-is-the-abyssal-price-source.md`). Opened on an owned module with an active Character, the line shows MutaMarket's estimate instead: looked up once on open, and imported only when the pilot presses "Ask MutaMarket to price this", beside a note that importing publishes the module, its rolls and its creator on a public MutaMarket page. Without an item id or a Character there is no estimate line.
