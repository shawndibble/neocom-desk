# Scope decisions — PI what-if add a planet for Bigger chains on Plan and Map (issue #2795)

_Recorded 2026-10-06 · issue #2795. Code: `src/features/pi/biggerChainsModel.ts` (`whatIfChainCandidates`, `estimateOnColoniesWith`, `estimateOnNewPlanetsWith`, `whatIfChainsView`), `useBiggerChains.ts` (`useWhatIfChains`), `BiggerChainsPanel.tsx`, `map/PlanMap.tsx`, `map/WhatIfChainsFeed.tsx`. Amends [20261006-154532](20261006-154532-pi-plan-bigger-chains-p3-and-p4-recommended.md) ("only the pilot's own planet types"; "no figure enters the Map")._

- **A what-if planet type may be added to a Bigger chain, one type at a time, only while the pilot hauls between planets.** It is the one-planet what-if's question ("what if I add a Barren planet?") asked of the Bigger chains model. With "I will haul between my planets" off, nothing changes on either tab, and nothing is priced.
- **The chains a type makes possible are the ones its pilot cannot make without it.** The same two layouts as 20261006-154532, with that type added. **On their colonies**: their real colonies plus one new planet of the type, at the ranking's own assumptions (Command Center level, extraction rate, customs). It has no system yet, so every leg to it reads "not known yet", never zero. **On new planets**: the chain estimate on new planets of their types and the added one. Either layout counts only when it uses the added planet, and both need a free planet slot for it. With no free slot, Plan and the Map say so and price nothing.
- **Never recommended, never in a pick, quick win, headline or total.** A what-if chain is a fact about a planet the pilot does not have. It is still compared, as a Bigger chain is, with the same planets on their best one-planet picks; the new planet counts as a free slot at the best one-planet recipe (the slot nudge's figure). The one-planet what-if (its unlocks, its best recipe) is unchanged.
- **Plan** lists it under the Bigger chains, in "What if I add a planet?": one collapsed line a type that makes a chain possible, the type whose best chain gains most first, priced only after the pilot's own chains. **The Map** prices only the ticked what-if (never a hovered one): the P3/P4 tiles it makes possible light with their multi-planet estimate (the "Est." mark, and "a Bigger chain on your planets" in the tooltip and accessible name), and the add-planet panel lists them. This is the only Bigger chains figure on the Map. Both tabs share one cache, so the second never prices again.
- **One planet is added, not several.** A chain that needs two planet types the pilot does not run is not offered from either. Trying pairs multiplies the solver runs by the number of type pairs.
