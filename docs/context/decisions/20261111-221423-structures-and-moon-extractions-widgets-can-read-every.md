# Scope decisions — Structures and Moon extractions widgets can read every corporation the pilot's Characters reach

_Recorded 2026-11-11._

- **Structures and Moon extractions are the first corp Widgets that can read All characters, on the Overview and the Corp Board.** A pilot with Characters in several corporations (one had 12) otherwise swaps Characters to see each corporation's structures. All reads every corporation any stored Character's roles and grant cover, once per corporation, merged into one list. A corporation that fails is left out while another answers; Retry shows only when all fail.
- **The Corp Board offers the scope choice only on a kind that can sum.** Every other corp Widget keeps the header Character's corporation and shows no control, rather than a disabled option. Wallet, jobs, members and the other corp reads stay per corporation until a ticket says otherwise.
- **No Corporation column yet.** A merged row is told apart by its structure name (system prefix); naming the owning corporation is a follow-up.
