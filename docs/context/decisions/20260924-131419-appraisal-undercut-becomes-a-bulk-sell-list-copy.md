# Scope decisions — Appraisal undercut becomes a bulk sell-list copy, plus a column picker

_Recorded 2026-09-24._

- **The Undercut toggle and its per-row "List at" column are gone, replaced by one "Copy sell list" icon button next to Share.** The toggle/column shape (#1504) turned out to be more UI than the job needed — a pilot who has decided to list wants one clipboard paste for EVE's Sell Items → Import prices, not a column to copy forty rows out of one at a time. The button copies `name<TAB>quantity<TAB>price` for every item with a seller to undercut (same `appraisalUndercut` price, same one-tick-under-the-hub math), skipping anything nobody is selling. Rules out ever bringing the toggle back as a _second_ way to reach the same prices — one export path only.
- **The Appraisal result table gets a `ColumnPickerMenu` (the `bpcSearchColumns.ts`/`marketOrderColumns.ts` pattern) for Buy each/Sell each/Buy total/Sell total/Refine total/LP store.** Requested alongside the undercut rework — with the "List at" column gone there was no way left to hide a column the pilot doesn't care about (a refine-only reader still gets every ISK/LP column). Quantity and Item stay mandatory, matching every other picker in the app (never the row's own identity). Refine total and LP store only ever appear in the menu once a row actually carries that data, same rule the columns themselves already followed inline.
