# Scope decisions — Page-level paste opens Fittings or the Appraisal directly

_Recorded 2026-10-02. Supersedes the first bullet of `20261001-211035-page-level-paste-offers-fittings-or-appraisal.md`; its other bullets stand._

- **A recognised page-level paste navigates straight to its destination — no toast, no confirm.** An EFT fit opens in the Fittings editor; an item list opens in the Appraisal. A mistaken paste is one Back away, and pages keep their own state across the trip, so the confirm step cost more than it saved.
- **One Back undoes the paste.** The Fittings editor replaces the paste's landing entry instead of pushing past it, so Back returns to the page the paste was made on, not an empty Fittings landing.
- **Settings › Shortcuts documents it** in a short "Paste anywhere" panel: the chord, and which paste opens where.
