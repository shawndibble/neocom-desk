# Scope decisions — Assets consolidation planner scope (issue #2874)

_Recorded 2026-10-07 · issue #2874._

- **The Consolidation Plan is one station, loose stock, a general-hold estimate.** The Assets page's Consolidate panel takes one destination station, lists each Character's loose (not assembled, not in a container or ship) stock elsewhere with packaged m3 and trips against the saved Cargo Space, and links Route Safety per Character. Out of scope for v1: per-item selection, Specialised Hold splitting, structures as destinations, multi-stop routes and persisting a plan. Nothing is stored; the destination is panel state.
