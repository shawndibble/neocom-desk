_Recorded 2026-10-28._

Unless the fit, as the swap leaves it, is stable with every toggled module (MWD, booster, weapon) switched off: the capacitor is then the pilot's to spend, so the swap is offered. Another flyable replacement that keeps the capacitor stable is still offered. Rules out a row whose Apply breaks the fit; a swap or implant that restores the capacitor is not searched yet.
