# Scope decisions — Spend my LP owned turn-ins are the active Character's

_Recorded 2026-11-15._

- **Spend my LP counts as free only the turn-ins the active Character owns, in
  its own hangars, and the plan says where they sit.** The plan used to count
  every account Character's stock and the corporation's (`detectOwnedStock`
  over all sources), so an alt's stack in another region read as free and the
  plan understated its purchases. An alt's or the corporation's items cannot be
  handed in by this Character without a trade, so they no longer count.
  Location is not filtered: an LP store redeems at any of its corporation's
  stations and the plan names none, so there is no single "store region" to
  filter to. Instead each row's owned note names the largest holding's location
  and how many other places hold some ("5 owned, in Jita IV - Moon 4 and 1
  more"), so the pilot judges whether the haul is worth it. Rules out a
  region-of-the-hub filter, which would hide stock a pilot would happily fly
  to its redemption station.
