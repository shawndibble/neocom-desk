# Scope decisions — PI fit has one source: the ranking's own fit (issue #2768)

_Recorded 2026-10-06 · issue #2768. Amends `20261005-123211` (recipe ranking) and `20261005-215512` (#2701). Code: `src/features/pi/planAdviceModel.ts` (`rankingFor`), `src/engine/pi/planRecipes.ts` (`RecipeLayout.fit`), `src/features/pi/findBestHowTo.ts`._

- **The recipe ranking's fit is the only fit.** Each ranked layout carries `fit` (level, CPU/Powergrid used, that level's budget) and `headsPerExtractor`, taken from the fit `recommendStopTier` scored it with: borrowed link cost, the pilot's typical storage, and the same heads. The "needs CC level N" tag, Show me how's "Needs a Command Center at level N" line, its CPU/Power meter and the Map drawer's "Figures assume a level N Command Center" all read it. Show me how no longer re-fits with default heads and no link cost. That second model is what made the tag and Show me how disagree, and what dropped P2's CC line.
- **Level = the tag's level for a tagged setup, else the lowest level whose budget carries the layout** (never above the pilot's level). The drawer names the tag's level for a tagged figure, the pilot's (or assumed) level otherwise.
- **A missing fit is said, not hidden.** Show me how prints "We couldn't work out which Command Center level this setup needs" instead of dropping the block.
- **Heads are stepped per P2, not just for the whole layout.** A P2 that does not fit at the ranking's head count gets the most heads (stepping by 1) that do fit, and the layout says how many ("Extractor with 6 heads"), so the pilot builds what the meter reads. With measured heads, P1 keeps the pilot's own count. A stepped P2's per-extractor rate is scaled by heads kept / the heads it stepped from, so fewer heads never earn as much. Fewer heads then means more extractors per block, so stepping only helps when the pilot's yield is richer than a P2 block needs. Where it is not, the P2 really does need the higher level, and the tag says so. An assumed count still first steps the whole layout down until some P2 fits, as before. This replaces "a measured count is never touched".
