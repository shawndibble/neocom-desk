# Scope decisions — Command palette opens by shortcut only (issue #2318)

_Recorded 2026-09-29 · issue #2318._

- **The command palette has no on-screen trigger; Ctrl+K / Cmd+K is the only way in.** The owner's call: the palette should take no room in the rail or atop a phone page until summoned. Settings › Keyboard shortcuts lists the chord. This rules out a rail search row, a phone search button, or any other visible opener — and so leaves the palette unreachable on a phone with no hardware keyboard, accepted as part of the call.
