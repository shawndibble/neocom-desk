# Scope decisions — Per-blueprint science skills cut manufacturing time (issue #1228)

_Recorded 2026-09-22 · issue #1228._

- **Manufacturing time applies every qualifying science/engineering skill the blueprint requires, at 1%/level (2%/level for Mutagenic Stabilization), on top of Industry/Advanced Industry.** A blueprint's `skills` list already names Industry/Advanced Industry alongside the science skills it requires — those two are excluded from the new `MANUFACTURING_TIME_SCIENCE_SKILL_PCT` table (`src/engine/industry/types.ts`) and applied via the existing fixed terms instead, so `timeModifier`/`jobDurationSeconds` never double count them. Qualifying skills are identified by their everef.net type description matching `/(\d+)% reduction in manufacturing time for all items requiring/i` — a narrower pattern than "reduction in manufacturing time" alone, which also matches Industry's own description. This rules out inferring the bonus from a skill's category/group instead of its literal description text, since not every science skill carries a manufacturing-time clause (e.g. Mass Production does not).
- **The bonus never applies to reaction jobs.** `timeModifier`'s existing activity branch (issue #513) already routes reaction jobs to the Reactions-only skill term before the science-skill table is ever consulted, so `blueprintSkills` is inert for `ctx.facility.activity === 'reaction'` without an extra guard.
