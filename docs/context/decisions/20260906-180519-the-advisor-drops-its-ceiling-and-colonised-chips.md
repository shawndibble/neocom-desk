# Scope decisions — The Advisor drops its ceiling and colonised chips

_Recorded 2026-09-06._

- **The Advisor's "Max upgrade" and "Colonised" chips are gone.** This
  narrows decision 20260904-174630's header-chip set. The Command Center
  ceiling is a fact about a skill that changes nothing a pilot does on this
  tab, and it is still stated where it actually bites: a colony behind it says
  so in its own detail modal, and an unbuilt planet's build plan refuses
  outright off an assumed one.

- **"N / M planets" was removed because it was misread, not because it was
  wrong.** It counts colonisable planets in the system on screen, and pilots
  read it as their colony allowance often enough that the "Colony slots" chip
  beside it existed largely to correct the misreading. Removing the misread
  beats annotating it. Colony slots and the customs rate stay: both are facts a
  pilot acts on.
