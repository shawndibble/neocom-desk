# Scope decisions — Make it fit offers training and implants, opened from per-budget Fix links

_Recorded 2026-10-19. Supersedes the "implants and skills are not part of this list" clause of `20261007-230641-make-it-fit-ranks-by-stat-loss-then` (#2828)._

- **Make it fit lists training and implants beside module swaps, in that order: Train, Implants, Swap modules.** A pilot whose Orca was 48 tf over on its drone rigs was offered only downgrades costing 21k EHP, though Drones Rigging IV fixed it for nothing; pointing at What to train and the Implant Finder hid the best answer behind two other tools. Training and implants cost the fit no stats, so they come before a swap, which always trades some. The three are not ranked against each other — time, ISK and stat loss have no honest common scale.
- **A skill fix is the lowest level of one skill that makes the fit fit; only when no skill does alone are the helpful ones combined**, all at V first and then each lowered while the set still fits (`findSkillFixes`). Every guess is the whole fit recalculated, so a rig-drawback skill counts exactly as the engine has it. Fixes list quickest to train first. Shown only for the active Character's real skills, as What to train is.
- **An implant fix is the Implant Finder's own cheapest fixes for the budget clicked**, offered only when it brings every budget under; calibration has no implant section.
- **Over budget, What to train keeps levels that only free CPU, powergrid or calibration, ranks them above every gain, and heads the list with the same fixes ("Makes it fit").** A fit that doesn't fit has nothing to improve yet. Within budget a CPU-only level is still left out, as before.
- **The trigger is a "Fix CPU" / "Fix powergrid" / "Fix calibration" link under each over-budget readout** — the Ring, the List and the stats card's Fitting section, whose over-budget figures (and header) go red — replacing the one "Make it fit…" link under all three. The dialog is titled after the link that opened it but still fixes every budget that is over. Drone bandwidth, cargo and the drone bay get no link: nothing Make it fit offers frees them. The collapsed header adds calibration's % only when calibration is the one over, so its red always has a number behind it. The "Fix" link is a text action though it opens a modal — a named exception in DESIGN.md §6c, since a box under the red figure would outweigh it.
- **An implant fix is searched on the budget whose link was clicked.** With CPU and powergrid both over, a CPU implant rarely clears powergrid too, so the section is often empty there; training or a swap carries that case.
