# Scope decisions — Fittings Ship Tree tab and Ship Info window

_Recorded 2026-09-26._

- **The Fittings section becomes Ships, with two tabs: Fittings and Tree.** The nav item reads Ships. `/ships/fittings` is the Fittings Start screen as it was, and `/ships` opens it; `/ships/tree` is the new Ship Tree. The editor and Compare move under `/ships/fittings/` and keep no tabs. Every old path redirects for good — above all `/fittings?f=`, which every Share Link ever copied carries — and `/skills/ships` (gone since #1911) lands on the Tree. A phone bottom bar that pinned Fittings keeps it, as Ships. The tree lives with fittings rather than Skills because clicking a hull leads to fitting it, and #1911 already put a hull's Mastery there; "Fittings" no longer named a section that also holds the tree.
- **The Ship Tree copies the in-game one (ISIS), checked against in-game screenshots.** One faction at a time. The main hull line runs left to right from a capsule. A size's specialised classes stack straight up above it — Navy classes directly above, the rest stepped right — and a line leaves the parent's class icon vertically and takes one 45° bend into the child's. Capitals (Carrier, Command Carrier, Titan) get a second trunk off the main line just left of the Dreadnought. The empire Corvette sits on its own lower row, rising into the Frigate and dropping to the industrial line (Shuttle, Hauler, Freighter). Non-empire factions put whatever classes they have on the main line in hull-size order (CONCORD: Shuttle, Covert Ops, Recon, Black Ops); ORE's hauler line sits on a lower row with the Bowhead below it. CCP ships the class list (`shipTreeGroups`) but not its shape, so the edges are hand-written, as every third-party tree does.
- **Every mark on the tree is the pilot's own progress.** A class whose required skills are trained is lit, its lines drawn as bright pipes; a locked one is dim, on thin lines. Under each class icon, one five-block bar per class skill fills to the level trained. A hull the pilot can fly is full brightness; one they can't is dim and grey. Gold is Mastery V only — gold corners, badge and tint on that hull — and a class label never turns gold. A gold Ω sits on the line where the next class needs an Omega clone (from each skill's Alpha cap), once per trunk.
- **Tile corners show what the hull is, always.** Orange "II" for Tech II, red "III" for Tech III, green ◇ for Navy and faction hulls — regardless of mastery, as in game. Every hull carries a winged mastery badge, empty until Mastery I.
- **Pirate classes link to their two parent empires.** Each pirate class has the two empires whose skills it needs above and below it; clicking one switches to that empire's tree.
- **Hover shows the in-game hover card; click opens the Ship Info window.** The card is the hull's render, name, class and bonuses. The window has four tabs: Description (class and faction, a short description and the bonuses), Fitting (slots, CPU, powergrid, calibration and drones, with Simulate opening a new Fitting of the hull), Skills & Mastery (required skills, Mastery I–V with each tier's skills, Add to plan) and Blueprint (where the blueprint can be had, and a button that starts an Industry Build Plan for the hull). The in-game window's Attributes and Industry-materials tabs are left out.
- **Desktop gets the map, a phone gets the ladder, and either can switch.** The ladder is the same tree read top to bottom: each main-line class a section, its specialised classes nested under it, the same marks. The choice is remembered.
- **The class icons and faction emblems are CCP's in-game art, kept in the app.** Copied from the EVE University wiki into `public/images/ship-tree/` rather than linked, so the tree never depends on the wiki staying up; credited to CCP under the Data credit. CONCORD, EDENCOM, the Society and the Deathless have no emblem there, so theirs show none.
