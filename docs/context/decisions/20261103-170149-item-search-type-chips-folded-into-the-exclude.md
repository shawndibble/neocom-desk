# Scope decisions — Item search: type chips folded into the Exclude menu, Saving column

_Recorded 2026-11-03._

- **The Items board's Saving column is the detail modal's Saving, and says nothing where one row cannot state it.** Units at the Trade Hub's best sell, less the ask, as a signed percent of that value. It follows the price flag's silence rules (`20261023-074200-items-board-flags-overpriced-single-type-contracts-silent.md`): a bundle or unknown line count, a blueprint copy, a contract that also asks for items or PLEX, a barter, an auction with no buyout, or no hub price yet. The modal prints a figure for some of these (it holds every line, and prices an auction at its starting bid); a column that guessed would disagree with it, so the cell is "–" and the modal remains the full answer. Held at the hub sell whatever the Below market side, since Below market replaces the table.
- **Item Exchange and Auction are Exclude entries, not chips.** The two type chips duplicated the Exclude menu's Auctions entry. Exclude now holds Item Exchange (`items.hideExchanges`), Auctions and PLEX contracts, all off by default, so nothing is excluded until the pilot says so. Excluding both leaves an empty board by the pilot's own choice. The old `items.kind` URL param is gone and an old link carrying it is ignored.
- **Every control in the filter sheet carries a caption.** Hide overpriced ("Price flags"), Include Other ("Other lines") and the Current System picker ("Current system") join the fields that already had one. The search box and the Below market and Columns buttons sit outside the sheet and name themselves.
