# Scope decisions — Build Opportunities ranks owned reaction formulas, gated on where they run (issue #5990)

_Recorded 2026-11-06 · issue #5990._

- **Ranked lists owned reaction formulas beside manufacturing blueprints.** The "Out of scope" lines of #642 and #819 that left them out recorded no reason. A player who owns formulas could otherwise only see a reaction's ISK/hour by opening each reaction plan by hand. A reaction row is priced exactly as the reaction Build Plan it opens: Reactions-skill job time, the formula's own (zero) ME/TE, and the facility, rigs, tax, security band and reaction cost index of the Character's **Remembered Location** for reactions (where a fresh reaction plan's Build Location starts). "All owned" now shows ISK/hour for a reaction formula too, borrowed from its Ranked row, which updates the #2335 note that reactions have none.
- **A reaction row whose Build Location is unset or in highsec is dimmed, not hidden, and never priced as lowsec.** Its profit, margin and ISK/hour are blank, the ISK/hour cell reads "Set reaction location" (All owned says the same), and it ranks below every priced row. "Unset" and "highsec" are the same answer the reaction Build Plan's own warning gives (`planReactionLocation`), so the two never disagree. The row click opens the reaction Build Plan, which flags the location and offers the fix; the panel gets no location control.
- **Rows stay single-level.** A reaction whose inputs are other reactions' outputs buys those inputs at market, as a reaction Build Plan and a manufacturing row do. Chain expansion stays a per-plan setting (**Include Reactions**).
- **One Manufacturing / Reactions filter for Ranked and All owned** (`?opps.activity`, default All). Ranked shows it only once a reaction formula is owned (or the filter is already off All), since with none there is nothing to choose.
- **The reaction Remembered Location reprices a batch only when the batch holds a reaction formula.** A manufacturing-only batch keeps its cached rows. A batch with reactions over the auto-recalculate limit asks for Refresh, manufacturing rows included, because the cache is per batch; their figures do not change.
- **Still out:** reactions in Market-Wide (no demand evidence; reach is a minority of industry players), PI, "fill my free reaction slots" scheduling, and planning from hangar stock as a separate mode.
