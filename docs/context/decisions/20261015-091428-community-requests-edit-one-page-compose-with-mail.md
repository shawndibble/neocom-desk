# Scope decisions — Community Requests: edit, one-page compose with Mail to chips, standard filter funnel

_Recorded 2026-10-15. Supersedes the "step 2" wording of the Request mail and Ask to copy decisions and ADR 0021's compose flow._

- **Compose is one page; recipients are a "Mail to" autocomplete with chips, no second step.** The chips sit under the field. The requester's own character is a chip from the start (marked "(you)"), so the Request also lands in their own in-game mail; Members sharing a matching blueprint and any holder an Ask to copy names are added as chips too, and anyone else is found by typing a name. It follows the mail composer's chip shape. Removing every chip posts without mail. Enter in the field only ever adds a Member, never posts; Escape closes the suggestions before the dialog.
- **The requester's own mail costs a slot** of the 100-a-day Request-mail cap like any recipient, and sorts first, so when the cap runs short it is other Members who are not mailed. Remove the chip to save the slot.
- **A requester can edit their own open Request** (location, terms, lines) through `editCommunityRequestCallable`; rules still deny client writes. Editing does not extend the expiry and sends no mail. A closed Request is reopened first; an expired but unclosed one can be edited. Pledges are keyed by line index, so once any Pledge exists the lines keep their items, kinds and order and only quantity, runs, ME and TE can change; the dialog hides add and remove then, and the server refuses a changed set with `lines-locked`. Lowering a quantity below what is Pledged is allowed (over-pledging already is). Pledgers are not notified.
- **Board filters use the page-standard Filters funnel (`FilterBar`).** Open / Mine / I can fill sit in it as chips at the select's height, with the shared Jump Range select (any, current system, 3, 5, 10, 15, 20 jumps) and the From system picker, measured from the Current System (a picked system, else the Character's location). With no system known the board says why and lists everything; the funnel then reads "Any distance".
