# Scope decisions — Assets bulk bar: Appraise replaces Add to Compare

_Recorded 2026-10-17._

- **The character Assets bulk bar has no Add to Compare; it has Appraise instead.** Bulk-adding to the Compare Set felt wrong because the bar never offered a way to open Compare. Appraise sends the selection (`Name xQty`, summed per type) to Market's Appraisal tab. The per-item context-menu Add to Compare stays, and Corp Assets keeps its bulk Add to Compare for now.
