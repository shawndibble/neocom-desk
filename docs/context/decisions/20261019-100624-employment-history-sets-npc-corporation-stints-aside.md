# Scope decisions — Employment history sets NPC corporation stints aside

_Recorded 2026-10-19._

- **NPC corporation stints are context, not career.** A pilot sits in an NPC
  corporation while idle or passes through one between player corps, so on
  the Employment timeline (page and Public Info modal) those stints draw as a
  slim dimmed line with an NPC tag: no logo card, no tenure bar, never
  RETURNED or SHORT STAY. The summary's corporation count ("Player corps") and
  Longest stay skip them, and tenure bars scale to the longest player-corp
  stint, so years of inactivity no longer read as the pilot's longest
  employer. They stay in the list and the CSV (hiding them would hide the
  gaps); a pilot with only NPC history gets no Longest stay.
  Current tenure still counts an ongoing NPC stint: it answers "how long in
  this corporation", and an idle pilot's honest answer is the idle spell.
