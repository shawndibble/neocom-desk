## Contract already enforced

Mobile rules proved by a component or a spec, so no run re-discovers them.

- **Control scale** — `controlStyles.ts` is the single source of `sm`=`h-9 md:h-7`/`md`=`h-11 md:h-9`, read by `Button`/`IconButton`/`FilterChip`/`TextInput`/`SearchInput`/`NativeSelect`/`SelectTrigger`. Only `md` reaches the real 44px touch floor — `sm` tops out at 36px on touch, so reaching for `sm` to "hit 44px" doesn't (caught filing #1055).
- **Table stacking** — `DataTable` defaults to `responsive="stack"`; the four `responsive="table"` opt-outs are `ContractDetailModal` (×2), `Wallet`, `Characters`, `LoyaltyStore`.
