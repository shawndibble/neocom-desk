## Already covered — don't re-propose

Mapped to the module/route that proves it, so a future run can verify fast:

- **Market**: undercut detection (`undercut.ts`), order competition/health
  (`orderCompetition.ts`, `orderHealth.ts`, `orderProblems.ts`), full raw
  order book as sortable table with context menu (Market Browser), hub-to-hub
  price gap for an owned sell order (`hubHaulGaps` in `orderExits.ts`).
- **Appraisal**: single-hub appraisal, multi-hub comparison (#689), refine-
  then-sell (#672), contract-line market value (#717), reprocessing
  (`reprocessing.ts`).
- **Industry**: realized profit (`realizedProfit.ts`), build-vs-buy/make-or-
  buy, Build Groups/Build Opportunities (multi-item planning — covers most of
  Ravworks'/Slipway's pitch), Order Depth column (`classifyOrderDepth` in
  `opportunities.ts`), open manufacturing job-slot count (#679), owned-stock/
  Craft Sweep detection (`ownedStock.ts`, materials only — not finished-
  product inventory), unowned-blueprint coverage ranking (#722), Active Jobs
  sorted-by-soonest with per-category slot usage (`ActiveJobsPanel.tsx`,
  `jobSlots.ts`), Production Log realized-profit chart (#711), price history
  charted (`PriceHistoryChart.tsx`) plus 7-day SMA (#730), reactions modeled
  as a manufacturing `activity` (no chaining across blueprints — see kill-test
  6/round 27).
- **PI**: stop-tier recommendation, fed/starved pin detection, reset-run
  batching, measured extraction rate, cross-colony coordination (ADR 0012,
  `network.ts`), resource-richness estimate and a fitted build plan for
  unbuilt/uncolonized planets — out-depths every third-party PI tool surveyed
  so far. Production Run/Log equivalent for PI batches (#725).
- **Wallet/LP**: balance-over-time chart (#690, `balanceHistory.ts`), corp
  wallet division sync (`engine/corp/assetDivisions.ts`), LP store ISK/LP
  ranking (`offerRows.ts`/`offerProfit.ts`).
- **Assets**: total portfolio value across locations (#712).
- **Open Orders**: sell-through/days-to-clear column (#713), multi-character
  aggregation (`CharacterFilterControl`).
- **Mining**: moon-ore ledger tax tracking (`groupMiningLedger`, renter-side
  post-hoc reconciliation only — no moon composition/pre-extraction data),
  ordinary ore/ice yield tracker (#671).
- **Quickbar**: price alerts on target price (#680), multi-hub Appraisal
  handoff (#726).
- **Restock**: on-hand vs. listed vs. par-level join across assets/orders/
  sell-through, with multibuy refill (#643, closed) — the "built X, how much
  is still unlisted" question is this ticket, not a new gap.

Also confirmed and settled: PI chain revenue/margin already prices at
`revenuePrices` end-to-end (`chain.ts`/`stopTier.ts`/`network.ts`); no market-
sell PI gap exists. Corp Industry Jobs' missing installer column is real but
deliberately out ("active jobs, not installer/location bookkeeping",
`src/esi/endpoints.ts`) and narrow-reach (corp directors only).

## Standing kill-tests

Reusable heuristics — check a new candidate against these before drafting:

1. **Cross-player aggregation wall.** Local-first PWA; ESI data lives in
   Dexie per device, never syncs across players. Kills: hub arbitrage/trade-
   route finders, corp ore-buyback/fleet-payout splitters, EQM-style member
   exchanges, buyback marketplaces (Eden Buyback-style).
2. **No write-scoped ESI.** `src/esi/registry.ts` has zero write endpoints —
   the app never places/cancels/modifies an in-game order
   (`docs/context/decisions/20260906-155913-open-orders-reads-as-a-worklist.md`).
   Kills bulk relist/buy-queue/order-automation candidates.
3. **Picture of data already on screen.** A chart/viz that just re-renders
   numbers already visible as rows is not new capability. Killed: order-book
   depth chart (twice), Gantt job-scheduling timeline (`ActiveJobsPanel.tsx`
   already answers "when do jobs finish" as rows).
4. **Engine exists but has one caller.** Caller *count* is not the signal —
   test exported vs. consumed capability: does the caller use every field the
   engine returns? Reprocessing/wallet balance chart were real gaps of that
   shape; `orderFloor`/`linkCost.greatCircleKm` came back clean (2026-09-10);
   `realizedProfit.ts`'s `salesTax`/`brokerFee`/`netRevenue`/`marginPct` were
   another real gap (#824, 2026-09-11) — its sole caller forwarded only 2 of
   8 output fields to the view layer.
5. **No historical ESI series.** System cost index has no ESI history at all
   (63% of systems sit at an identical floor) — kills any cost-index-over-time
   feature.
6. **Settled scope wins.** Always check `docs/context/decisions/` and
   `.out-of-scope/` before drafting. Named precedents: ADR 0013's Firestore
   write-budget limit (public-contract crawling at scale); blueprint research/
   invention/copying planning (no market price for the output, `.out-of-
   scope/`); round 27's Bill-of-Materials-rollup rejection (`BuildPlanRecord`
   is one blueprint per plan, no chaining reactions/blueprints into one
   computed plan — kills multi-hop reaction-chain profitability tools).
7. **Assets endpoint has no timestamp.** No acquisition/last-touched field —
   kills staleness/idle-inventory detection.
8. **Not in a poll domain ≠ regularly sampled.** A locally-accumulated series
   only works if the underlying fetch happens on a schedule
   (`src/features/notifications/pollDomains.ts`). Assets is page-visit-only —
   killed Total Assets Value chart over time on sampling cadence.
9. **A scope being wired for one feature doesn't make it free for another.**
   `esi-markets.structure_markets.v1` (`structureMarkets` group, #538) is
   fetchable but has zero settings-page consent UI — treat unbuilt consent UI
   as part of the cost, not a formality.
10. **Materials are fungible — no per-unit purchase provenance.** Settled
    project-wide (`docs/context/decisions/20260905-181537-...md`), naming
    EVE Tycoon/jEveAssets/ETMv2/Industreaux's FIFO approach and rejecting it
    for both Production Run linking and any pure station-trading/FIFO P&L
    tracker built from wallet transaction history.
11. **A `ref_type` filter on the Wallet journal already exists**
    (`walletJournalFilter.ts`). A "view of journal entries with ref_type X" is
    usually a saved filter, not new capability (kill-test 3 extended). Killed:
    LP Store redemption ledger off `ref_type: lp_store`.
12. **A module's own header comment can be a settled decision.** Not every
    scope boundary lives in `docs/context/decisions/` — some are inline JSDoc
    with a stated reason, same weight. Killed: PI Advisor arbitrary-system
    search (`AdvisorPanel.tsx`'s header already rejects it).
13. **A one-shot pre-investment calculator with no ESI ground truth to
    validate against is a maintenance trap, not a feature.** A tool whose core
    formula depends on CCP mechanics that aren't SDE-derivable and have no
    ESI fixture to check correctness against (extraction/reserve-depletion
    rates, Metenox fuel-block reaction ratios) rests on hand-transcribed
    community numbers that go stale silently on the next balance pass, for a
    calculation most players run once per decision rather than repeatedly.
    Killed: Moon Survey / Metenox Yield Estimator.
14. **No bulk market-history endpoint.** ESI's `/markets/{region_id}/history`
    is one type ID at a time; a market-wide "movers/trending items" scan needs
    history for thousands of types per region — heavier than the crawl ADR
    0013 already rejected for the much smaller public-contracts dataset.
    Narrowing to an already-bounded set (Quickbar/appraisal history) mostly
    collapses into a sort over the existing per-item Price History chart
    (kill-test 3). Killed: Market Movers / Trending Items dashboard.
