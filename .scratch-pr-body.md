## Summary

- Splits the plan editor's single flat button row into a compact **Import / Export** area (import from in-game queue, import from clipboard, and a single expandable **Export** dropdown offering "to clipboard" / "to CSV") and a separate, sticky-pinned **Toolbar** (optimize remaps, add remap marker, optimize at markers, suggest reorder) that stays visible above the entry list while it scrolls.
- "Suggest reorder"'s accept/reject preview now opens in the app's shared `Modal` component instead of an inline panel; Accept and Reject both close it. "Optimize remaps" and "Optimize at markers" results are untouched — still inline, read-only.
- No change to what any action computes or persists.
